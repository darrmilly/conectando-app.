# Conectando

Conectando es una **web app de traducción de voz a voz en tiempo real**.  
Permite que la abuela (que habla español) y los nietos (que hablan inglés) se comuniquen fácilmente por teléfono o cualquier dispositivo con navegador.  

- Traduce del español al inglés y del inglés al español al instante.  
- Funciona como una **app privada** para los usuarios que tengan el enlace.  
- Ideal para familias que necesitan comunicación inmediata sin aplicaciones complicadas.
